# 足球移动端 UX 对齐清单

以 HomeMew Web 的足球列表、管理页、统一表现表单和统计看板为基准，覆盖整套 Mini 足球流程。功能和数据语义保持一致；原生平台适配明确记录如下。

| 范围 | Mini 同步结果 | 微信适配 |
| --- | --- | --- |
| 导航与常用操作 | 图标记录／统计标签；图标筛选、新增、刷新；管理／活动短入口 | 全部业务操作放在胶囊避让导航栏下方，至少 44px 触控热区 |
| 球员和筛选 | 同一家庭球员、年份、比赛类型、赛事、双方球队和备注搜索 | 标签同页切换，保留当前范围；家庭球员／日期使用原生 picker |
| 球队／赛事选择 | 已选名称按 ID 补读、最近选择、至少 2 字搜索、320ms 防抖、清空、分页 | 共用底部面板；最近项经 BFF 验证后再选中，× 仅清本机缓存 |
| 快捷创建 | 仅成功的零结果搜索显示新建；确认后保存并回填 | 原生确认弹窗；错误、加载和迟到结果不开放创建 |
| 比赛列表 | 双方图标、性质图标、紧凑比分、赛事标签、记录和编辑各自入口 | 名称截断，整行也可进入详情；刷新不提交尚未搜索的输入 |
| 表现详情 | 八项中性快捷入口、完整计数、出场记录、更多类型、记录编辑 | 两列快捷按钮；表单滚动区与固定操作区，系统胶囊区域不放按钮 |
| 统一表现表单 | 进球／射门／出场专属字段、可选信息提示、取消／确认保存、错误和防重提交 | 原生类型 picker；保存中锁定字段和关闭；未确认不写入 |
| 球队与球员管理 | 常用球队及有界搜索、球队成员、其他球员、编辑／删除、引用和版本检查 | 一套短标签和图标按钮；家庭成员由家庭管理维护 |
| 统计看板 | 总体数据、场均进攻／时间效率／场均防守、自然月双折线、独立场次柱图 | 原生横向滚动；同时提供可读月度数值；缺失值断线并显示 — |
| 空态／失败／并发 | 无结果、读取失败、保存失败各自展示；部分计数不冒充完整值 | 关闭搜索面板后丢弃迟到请求；切家庭、切球员后丢弃旧响应 |

## 验证证据与边界

- `apps/miniprogram/tests/football-ui.test.ts` 覆盖共享范围、历史统计深链、确认写入、版本错误、完整分页计数、最近项验证、迟到请求、零结果创建和自然月图表。
- 小程序 TypeScript 检查、JS 构建和全套回归；Web TypeScript、构建与足球相关测试。
- 使用本机微信开发者工具随附的 `wcc.exe` 和 `wcsc.exe` 编译足球 WXML / WXSS 及相关自定义组件，确认模板、表达式和样式能被原生编译器接受。
- 以实际 WXML / WXSS 和隔离的示例数据生成源码预览，检查 320、375、430px 下的空态、长队名、展开筛选、详情、录入、管理及有数据统计。它用于布局 QA，不冒充 WeChat WebView 运行验收。
- 本次开发者工具窗口自动访问授权超时，未完成真实 WebView、键盘和原生 picker 的现场交互验收；没有向真实家庭写入测试比赛或表现，没有部署或提交审核。

平台边界：继续使用既有显式 Mini BFF，LifeSpace 是持久化、引用和授权权威；本机最近项和球员偏好仅为 UI 状态。
